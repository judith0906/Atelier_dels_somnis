# ✨ Atelier dels Somnis

Página web oficial de Atelier dels Somnis, un espacio creativo dedicado a la enseñanza artística, actividades culturales y alquiler de salas para eventos en Reus (Tarragona).

Permite a los usuarios descubrir las clases y talleres disponibles, consultar promociones, conocer los espacios de alquiler y contactar con el centro.

## 📌 Características

* Diseño visual inspirado en una estética artística y creativa
* Sistema multidioma (Español / Catalán)
* Catálogo interactivo de clases y talleres de arte, música y danza
* Galerías dinámicas e imágenes de muestra para cada actividad
* Sección de promociones actualizable mediante flyers
* Información sobre alquiler de salas para celebraciones, eventos y actividades
* Navegación responsive adaptada a dispositivos móviles y escritorio
* Animaciones de aparición mediante scroll reveal
* Menú hamburguesa para navegación móvil

## ⚙️ Tecnologías usadas

* **Lenguajes:** HTML5, CSS3, JavaScript Vanilla
* **Tipografías:** Cinzel, Cormorant Garamond y Lato (Google Fonts)
* **Internacionalización:** Sistema de traducción propio mediante JavaScript
* **Sin frameworks ni dependencias de compilación**

## 📁 Estructura del proyecto

* **`index.html`** — Página principal del sitio web
* **`styles.css`** — Estilos globales, animaciones y diseño responsive
* **`script.js`** — Funcionalidades dinámicas, traducciones y efectos interactivos
* **`assets/images/`** — Recursos gráficos, logotipos, flyers, iconos y galerías
* **`assets/images/clases/`** — Imágenes de actividades y talleres
* **`assets/images/casals/`** — Fotografías de eventos y actividades especiales
* **`assets/images/flyers/`** — Promociones y cartelería publicitaria
